# Sistema Informático - Buen Vivir

Repositorio de mocks (prototipos de interfaz) del sistema de gestión para el Centro de Ecología Integral - Buen Vivir.

## 🚀 Cómo visualizar los mocks

### 1. Instalar dependencias

```bash
pnpm install
```

### 2. Levantar el entorno de desarrollo

```bash
pnpm run dev
```

### 3. Acceder a los mocks

Una vez iniciado, los mocks estarán disponibles en:http://localhost:5071/

## 📋 Requisitos previos

- Node.js instalado
- pnpm instalado globalmente (`npm install -g pnpm`)

## 🛠️ Notas

- Si el puerto `5071` está ocupado, verificá la configuración del proyecto para cambiarlo.
- Ante cualquier error en `pnpm install`, revisar la versión de Node.js compatible con el proyecto.
